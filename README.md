# VisionBill: The Intelligent Receipt Analytics & Social Splitting Platform

VisionBill transforms static, cluttered paper receipts into dynamic, actionable "Visual Carts." Designed for the modern retail era, it bridges the gap between physical shopping and digital financial tracking.

---

## 🚀 Unique Selling Propositions (USPs)

*   **Item-Level Granularity**: Capture every single line item, not just the total spent. Turn dead paper into live, searchable data.
*   **The "Visual Cart" Experience**: A premium, familiar UI inspired by top delivery apps (Zepto, Instamart) that eliminates bill fatigue.
*   **Long-Bill Ghosting Tech**: Proprietary multi-segment scanning with "ghosting" alignment to handle even the longest 2-foot grocery bills.
*   **Social Fabric Integration**: One-tap itemized splits sent via WhatsApp with integrated UPI payment links for frictionless settlement.

## 🛠️ Technical Stack

- **Backend**: NestJS, MongoDB, Gemini 1.5 Flash (AI OCR).
- **Frontend**: React Native (Expo), TypeScript, Axios.
- **Styling**: Vanilla CSS (Premium Dark/Glassmorphism).

---

## 🏗️ Getting Started

### Backend (NestJS API)
1. Navigate to `vision-bill-api`.
2. Install dependencies: `npm install`.
3. Configure `.env` with `MONGODB_URI` and `GEMINI_API_KEY`.
4. Start dev server: `npm run start:dev`.

### Frontend (Expo App)
1. Navigate to `vision-bill-app`.
2. Install dependencies: `npm install`.
3. Start Expo: `npx expo start`.
